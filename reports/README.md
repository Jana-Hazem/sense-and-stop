# Reports

This directory holds written project reports and the literature review that informs the study. Keep background synthesis distinct from this repository's own methods and future results.

## Current literature review

- [Literature review synthesis](literature_review/literature_review.md) is the project-focused synthesis of the team's Neuroflux review PDF.
- The supplied PDF's title page contains student IDs, so the source PDF is not copied into this repository. The synthesis cites the sources listed in that review; verify primary sources before relying on quantitative claims.
- The review discusses broader migraine biology and clinical topics. This repository remains a computational framework: it does not claim scalp EEG records human CSD and makes no clinical claims.

## Adding report material

Place new report drafts in a clearly named subdirectory or Markdown file. Include the purpose, version/date, contributors, and citations. Keep literature synthesis, project methods, and any future results clearly identified as separate sections. Do not place raw recordings or other raw data in this directory.
