# Literature review

This folder contains the team's project-focused literature synthesis. It draws on the Neuroflux literature review supplied with the project; it is not a new systematic review.

See [`literature_review.md`](literature_review.md) for the synthesis and references. Keep claims tied to the listed sources, and check the primary papers before reusing quantitative values or making stronger claims. The source PDF is retained in the project materials outside this repository because its title page includes student IDs.
